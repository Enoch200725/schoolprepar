1. Titre et description

Schoolprepar est un platforme d'orientation et de préparation scolaire crée par le framework symfony.

2. Analyse fonctionnelle
Vous trouverrez le digramme de contexte statique qui liste les utilisateurs qui interagissent avec le système, le diagramme de cas d'utilisation qui liste les fonctionnalités du système et un diagramme d'entité-rélationnel tous dans un pdf  zippés dans un dossiers.

3. Guide d'installation
 voici les étapes à suivre pour faire fonctionner le projet.
	1. clôner le git

	2. Installer les dépendance avec composer install
	
	3. configurer le fichier .env 
	
	4. lancer le serveur avec symfony serve
